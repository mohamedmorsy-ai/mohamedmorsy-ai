## 🚀 Featured Project

### 🌍 [Global Economic Data Analysis & Forecasting](https://github.com/mohamedmorsy-ai/Global-Economic-Data-Analysis)

A data analysis and forecasting project exploring **GDP growth, inflation, and unemployment across 20 countries from 1990 to 2025**.

- Prepared and cleaned economic data, including missing-value checks and exploratory analysis.
- Engineered time-based features for predictive modeling.
- Compared a **previous-year baseline, Linear Regression, and Random Forest** using historical evaluation.
- Built and deployed a **Streamlit dashboard** to make the results easier to explore.
- Presented **experimental 2026 GDP growth estimates** with clear data-quality considerations and limitations.
